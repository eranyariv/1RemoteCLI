Change history

The major enhancements and bug fixes in every build.

This is the user-facing history, not a list of every internal change. Releases are shown newest first.

v0.29 21 August 2026

  • Enhancement. Copilot questions now appear as selectable menus on the session page, and compact, summary, and full controls let you choose how much tool activity to show.
  • Bug fix. Long session messages, paths, and status details now stay within the phone viewport instead of making the page scroll sideways.

v0.28 21 August 2026

  • Enhancement. The Windows agent tray icon now opens its menu with a single left click or keyboard activation, and its tooltip shows the app name, current version, connection state, machine, and session details.

v0.27 20 August 2026

  • Bug fix. Large Copilot conversations now load reliably in the web app, and an empty conversation is identified instead of remaining on “Loading the transcript”.

v0.26 20 August 2026

  • Enhancement. Desktop shortcut setup now shows the detected CLI type for confirmation or override before creating anything. Copilot shortcuts create native ACP chats, while Claude Code, PowerShell, Command Prompt, and generic shortcuts keep the shared-console flow with the confirmed type shown consistently in the agent and web app.

v0.25 20 August 2026

  • Bug fix. The Windows agent Settings window now renders consistently in dark mode instead of mixing a bright white tab page with dark labels and controls.

v0.24 20 August 2026

  • Enhancement. Touch devices now get a clearly labeled Enter control in terminal sessions, and long project or session content no longer scrolls the page sideways.
  • Bug fix. GitHub Copilot chat discovery now matches the sessions visible in the desktop app instead of including its broader ACP history.

v0.23 20 August 2026

  • Enhancement. The Windows agent now discovers up to 100 recent chat sessions across ACP pages instead of stopping at the first 20.

v0.22 20 August 2026

  • Bug fix. GitHub Copilot chat sessions now use the same descriptive source label in the web app and Windows agent Settings.

v0.21 20 August 2026

  • Bug fix. Session project assignments now survive hub and agent restarts instead of returning to General.
  • Enhancement. Unmapped sessions can now suggest a matching project from their working directory, program path, or repository name.

v0.20 20 August 2026

  • Enhancement. The built-in General project now has its own distinct icon instead of using the 1RemoteCLI app logo.
  • Enhancement. Windows agent Settings now shows the local session count and clearer progress while checking for and installing updates.
  • Bug fix. Archived GitHub Copilot sessions are hidden from 1RemoteCLI by default, with a new agent setting to show them when needed.

v0.19 20 August 2026

  • Enhancement. Projects, machine panes, and sessions can now be reordered by dragging, with each layout remembered between visits.
  • Enhancement. Project pages now show their icon, description, and links, while inactive machines are grouped at the bottom and collapsed by default.
  • Enhancement. Reorganized the Windows agent Settings window into tabs for clearer connection and agent configuration.
  • Enhancement. The Windows agent now shows local sessions in a sortable, resizable table and remembers the table layout, active tab, and window size.

v0.18 20 August 2026

  • Enhancement. Added a complete public change history, linked from the homepage, Readme, and Windows agent Settings window.
  • Bug fix. Project creation and editing now explain invalid names, descriptions, and URLs instead of showing a generic error.

v0.17 20 August 2026

  • Enhancement. Added an icon picker to the new-project dialog, including previewing and resizing the image before it is uploaded.

v0.16 20 August 2026

  • Bug fix. Corrected wrapped update-status text in the Windows agent Settings window.

v0.15 20 August 2026

  • Enhancement. Added per-user projects for grouping sessions, with project descriptions, links, icons, and session reassignment.
  • Bug fix. Hardened project persistence so interrupted writes cannot corrupt saved project definitions.

v0.14 19 August 2026

  • Enhancement. Added ACP chat sessions: continue recent GitHub Copilot or Claude Code conversations from a phone, including messages and eligible permission responses.

v0.13 19 August 2026

  • Enhancement. Added verified agent self-update through the tray, Settings window, and 1remote update.
  • Enhancement. Added phone-side session naming and pinning.
  • Bug fix. Self-check now tolerates a temporary lock on its working directory.

v0.12 19 August 2026

  • Bug fix. The agent starts without creating a visible console window.
  • Bug fix. Sessions correctly identify tools launched through desktop shortcuts.

v0.11 19 August 2026

  • Enhancement. Sessions identify the CLI they are running so the phone can offer controls appropriate to that tool.
  • Bug fix. Improved the Task Scheduler fallback and made Windows ASR startup-block guidance more precise.

v0.10 19 August 2026

  • Enhancement. Updated the tray and Settings window with native Windows 11 styling.
  • Bug fix. Hardened installation and shutdown, including installation when the GitHub API is unavailable.

v0.09 18 August 2026

  • Bug fix. Release executables are no longer compressed, avoiding managed-device launch blocks.
  • Bug fix. Installation starts the agent immediately, so the machine appears without another Windows sign-in.

v0.08 18 August 2026

  • Bug fix. Added clear Windows startup diagnostics, including why a first run was blocked and whether waiting can resolve it.
  • Bug fix. Hid the console window created by the logon task.

v0.07 18 August 2026

  • Enhancement. Added the public getting-started page and a working one-line installer.
  • Bug fix. Installation retries agent startup while Microsoft Defender is still scanning a newly downloaded build.

v0.06 18 August 2026

  • Enhancement. Refined product branding across the tray icon and Settings window.

v0.05 18 August 2026

  • Enhancement. The tray icon reflects connected, disconnected, and reconnecting states.

v0.04 18 August 2026

  • Enhancement. The tray icon displays the live session count.

v0.03 18 August 2026

  • Enhancement. Added a Settings window and the ability to create shareable copies of desktop shortcuts.
  • Bug fix. Preserved UTF-8 console output and made Settings available when the agent starts hidden.

v0.02 18 August 2026

  • Enhancement. Reduced the Windows agent package from roughly 70 MB to 13 MB and expanded its tray controls.
  • Bug fix. Improved trimmed-build installation and avoided self-checks for a processor architecture the current machine cannot run.

v0.01 17 August 2026

  • Initial release. Securely share live Windows CLI sessions to a phone, with Microsoft Entra sign-in, terminal output and input, reconnection, push notifications, tray controls, and an installable web app.
